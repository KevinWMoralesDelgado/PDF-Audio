# PDF to Audio Converter

A simple Python tool that converts PDF documents into spoken MP3 audio files using Google Text-to-Speech (gTTS).

---

## 🌟 How It Works

The program runs in three straightforward steps:

1. **Smart File Checking:** Asks for your PDF file name and checks that the file exists and is actually a PDF before starting.
2. **Text Extraction:** Reads text page-by-page while showing a clean live progress update in your terminal.
3. **Audio Generation:** Converts the extracted text into audio and saves it as an MP3 file with the same name as your PDF.
